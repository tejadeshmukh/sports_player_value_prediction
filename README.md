
# Sport  Regression Analysis

## Project Overview

This project aims to perform a  regression analysis on player statistics to understand the relationship between various player attributes and their market value. The goal is to build a predictive model that can estimate a player's value based on their characteristics and skills.

## Data

The dataset used in this project is `player_stats.csv`, which contains various attributes for football players, including:
- Player information (name, country, age, height, weight, club)
- Skill ratings (e.g., ball control, dribbling, passing, shooting, defending, physical attributes)
- Player market value

The data preprocessing steps involved handling missing values, cleaning and converting the 'value' column to a numerical format, and preparing the data for regression modeling.

## Analysis and Modeling

The analysis includes:
- Exploratory Data Analysis (EDA) to understand the distribution of player values and the relationships between different attributes.
- Data preprocessing, including handling categorical variables and scaling numerical features.
- Applying various regression models to predict player value.
- Evaluating and comparing the performance of different models.

The project specifically focuses on  regression, aiming to model the relationship between multiple independent variables (player attributes) and the dependent variable (player value).
